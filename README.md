# ex44-orchestrator

The EX-44 Home: one page that shows what needs Ali, every chat on the four accounts, the job tree, what is held off main, the skills, and how it all works.

- This repo holds page code only. It holds no data.
- The page reads the live state from a private repo in the browser, with the viewer's own GitHub key. The key stays in that browser.
- Test cases show only with `?test=1` in the address.
- The page is built from the approved design on EX-44; do not edit `index.html` by hand.
- A privacy check runs before every push and on GitHub after it. It only warns; it never blocks.
